Chat de Aula - E.E.S. N°7 de Merlo
Sistema de comunicacion en tiempo real para el aula, desarrollado para la Escuela de Educacion Secundaria N°7 de Merlo, Provincia de Buenos Aires, Argentina.
Descripcion
Este recurso permite al profesor administrar una sala de clase virtual con hasta 40 mesas. Los alumnos ingresan mediante un codigo dinamico enviado por WhatsApp. No requiere registro ni contrasena.
Funciones principales
40 mesas con indicador visual de estado (libre, conectado, hablando, pide palabra)
Audio bidireccional - el profesor puede habilitar el microfono de los alumnos
Chat de texto - consignas, links y mensajes privados
Modo examen - bloquea microfonos, solo permite escribir
Historial persistente - se guarda en el navegador
Indicador remoto - identifica alumnos conectados desde casa
Exportacion a Word - los alumnos guardan su trabajo
Como usar
Profesor
Abrir profesor.html
Activar el microfono
El sistema genera un codigo de sala automaticamente
Copiar el link y enviarlo por WhatsApp al grupo del aula
Administrar las 40 mesas desde el tablero
Alumno
Abrir el link recibido por WhatsApp
Ingresar el numero de mesa (1 al 40)
Opcional: poner nombre y marcar si esta conectado desde casa
Tocar "Entrar a la clase"
Tecnologia
HTML, CSS, JavaScript puro
MQTT (broker publico HiveMQ) para mensajeria en tiempo real
PeerJS para comunicacion de audio WebRTC
Sin frameworks, sin backend propio, sin costos
